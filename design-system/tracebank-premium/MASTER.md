# TraceBank Premium · Design System

本文件是本轮界面规则的来源，复用现有 React、Tailwind、SVG、状态与 API。方向：白色与冷灰主面、深海军蓝文字、少量实心靛紫强调的银行工作台。根据用户最新要求取消绿色品牌识别。不要添加营销 Hero、渐变、玻璃、发光或随机装饰。

## 语义色

背景 `#F5F7FA`，主面 `#FFFFFF`，导航 `#EEF2F6`，次级面 `#F6F9FC`，主文 `#0A2540`，次文 `#425466`，元数据 `#53677B`，普通边界 `#D9E2EB`，交互边界 `#7C8FA1`，弱分隔 `#E6EBF1`。元数据与交互边界须经实际对比检查。

配色参考用户提供的 [PayFlow 演示页](https://uupm.cc/demo/payment-gateway)：实际浏览器取样得到白底、深海军蓝文字 `#0A2540`、Slate 次文 `#425466`、靛紫强调 `#635BFF` 与弱分隔 `#E6EBF1`。用户明确要求去掉绿色后，主按钮、导航选中、焦点、图表与品牌标记统一改为靛紫。参考页的营销布局、认证标识和商业数字不引入银行工作台。

主操作 `#635BFF` / hover `#5147E5` / pressed `#4338CA` / on-primary 白。选中背景 `#EEEDFF`，选中文字 `#4434B8`。成功深蓝、警告深棕、失败砖红、处理中深青，各配独立浅底与文字/图标，不单靠颜色。图表靛紫线与低饱和灰蓝辅助色；页面保持中性色面积占优。

所有实际颜色集中在 `tokens.css`。白底普通文字≥4.5:1；互动边界与焦点单独检查。Disabled 使用明确的灰面/灰文，不把整个组件减到极低透明度。普通容器不浮起，Popover 与 Dialog 才使用较明显阴影。

实心主按钮使用 primary 配白字；浅底上的链接和小字使用更深的 primary-text，避免直接把亮靛紫用作所有文字。成功同时显示勾号/状态词，警告和失败使用图标与明确文案。

## 字体与尺寸

Manrope（自托管 Latin/数字）+ 中文系统 UI 黑体；正文 14–16、控件与表格 13–14、caption 12、元数据最低 11、区标题 16、页面标题 26。金融金额 tabular-nums。中文正文正常字距，行高 1.65–1.8。手机输入与正文 16，主要点击目标≥44 CSS px；桌面密集控件至少 32，主要按钮 38–40。

4px 间距标尺：4/8/12/16/20/24/32/40。圆角 4/6/8/12；图标 14/16/18/20/24。边框 1px，焦点 2px + 3px offset；小控件与大控件按语义区分，禁止统一胶囊化。

## 布局

导航 224，可收至 72；移动端抽屉。工作区主列自适应，执行面板默认 340、可展开至 420 或收起；1280 笔记本默认 316，768 将计划放在主区下方，不横向挤压。主内容限制阅读宽度，输入区贴近业务内容；空态不制造半屏无意义留白。五页面共享标题、表格、筛选与分页标准。

## 交互与状态

- Primary 主提交 / Secondary 有边框 / Tertiary 轻操作 / Destructive 取消或破坏性动作。所有按钮有 hover / pressed / focus / disabled，异步有 loading。
- Ctrl/Cmd+K 打开导航与任务检索；只导航、打开历史或预填需求，不发起资金业务。Escape 关闭、方向键选择，焦点返回。
- 场景选择器支持键盘、Escape、外部点击关闭；Prompt 自动高度，Enter 提交、Shift+Enter 换行、保留中文输入法组合保护。
- 执行过程基于 run.events，回答晚于实际执行结果。进度只用已完成节点 / 实际总节点。失败不展示成功图标；未知结果只查原操作。
- 依赖图来自 plan.nodes；实际 viewBox 缩放 50–200%、0 复位、+/-、箭头平移与拖动、Alt+滚轮。浏览器原生 Ctrl/Cmd 缩放保留。步骤列表始终可切换。
- 默认电话脱敏，用户显式展开核对；授权字段包含人、金额、卡片/业务、风险与有效期。验证码只在独立窗口。
- Modal 原生 dialog；Tooltip 同时覆盖 hover/focus；Tabs 有 selected 与键盘状态；Skeleton 仅在实际加载，Toast 可关闭。

## Motion

普通颜色反馈保留 100/160ms；React 动效由 `src/motion.tsx` 统一配置，使用 Motion 14.5.0。页面退出 100ms、进入 240ms，位移 −4/8px，旧页退出时 inert，避免旧操作仍可点击。按钮按下 80ms 收至 0.97（小图标 0.92），释放使用 stiffness 460 / damping 20 / mass 0.6 的弹簧；鼠标、触控与键盘一致，禁用按钮和遮罩不缩放。

时间线节点以实际 ID 稳定入场，最大交错延迟 140ms；完成连线按真实 succeeded 状态用 350ms scaleY 点亮，运行标记只在真实 running 且未暂停时低幅呼吸。轮询不会重播整个时间线。工具记录展开/收起使用 220ms 的 height 与 opacity，这是内容高度过渡的限定用途；退出记录 inert。其余主要使用 transform/opacity，不给金融结果制造假打字或等待。

reduced-motion 禁止弹簧、位移、脉冲与高度过渡，保留静态状态。应用订阅媒体偏好变化，打开页面后修改系统设置也立即生效。滚动条用中性 token。视觉帧采样、录屏及限制见 `docs/motion-ui-qa.md`。

## 安全与验证

不改权限、工具、路由、API 与后端金额校验；演示标识持续可见。敏感操作不添加自动重试。只读恢复可刷新，写任务失败提供检查记录/人工入口而不假装回滚。检查四视口、键盘、CSP、对比与实际账户状态；把审查、截图、迭代与限制记录在本轮 QA 报告。
