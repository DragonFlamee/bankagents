## 业务要求

| ID | 要求 | 当前交付与证据 |
| --- | --- | --- |
| BIZ-001 | 智能转账 | 姓名/别名/手机号、澄清、确认、累计升级、幂等回执；银行/API/固定任务和浏览器验证 |
| BIZ-002 | 余额及交易查询 | 归属校验与期间筛选；绿色无二次确认 |
| BIZ-003 | 账单分析 | 月/上月/本年、分类、收支、异常证据与原交易ID；固定测评复算金额；非已训练的完整欺诈模型 |
| BIZ-004 | 卡片管理 | 查询、挂失/解挂、模拟虚拟卡；写入按风险授权，挂失有浏览器实录 |
| BIZ-005 | 订阅管理 | 查询/取消按题面采用黄色；银行/API/固定任务测试；未连真实商户 |
| BIZ-006 | 跨场景 | 明确有序组合和合法DAG，目标记录不冻结资金；4个复合任务验证 |
| BIZ-007 | 预约、AA、生日购物 | 未实现，题面典型示例作为扩展，不纳入完成场景 |
| BIZ-008 | 理财操作 | P2未实现，不能把已装技能当业务功能 |

至少三个核心方向有离线与真实模型固定集端到端证据；账单纠错学习、任意隐含意图及开放语言覆盖仍不能据小型联调集宣称完成。
