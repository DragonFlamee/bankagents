# 赛题要求与实现

依据[原始赛题](../problem.md)核对。所有业务运行在模拟账户中；代码实现与真实银行上线分别评估。

## 六类业务

| 方向 | 实现 | 证据 |
| --- | --- | --- |
| 智能转账 | 姓名/手机号、澄清、单次/月度预约、AA | 银行、场景、预约及API测试 |
| 账单分析 | 分类、期间对比、异常线索和来源交易 | 账单与答案测试 |
| 理财 | 8题测评、模拟产品、适当性、申购赎回及持有期 | 场景与银行测试 |
| 卡片 | 申请、额度、交易限制、冻结、挂失和密码重置 | 场景与权限测试 |
| 订阅 | 周期识别、提醒和取消 | 场景及API测试；查询与识别授权区分须说明 |
| 跨场景联动 | 纪念日查询、锁定资金、引用回执预约鲜花/蛋糕 | 五节点DAG和锁定/订单测试 |

## 核心技术

| 要求 | 当前实现与边界 |
| --- | --- |
| 三级权限 | 绿色读取、黄色确认、红色操作绑定OTP；普通与到期转账均复核实际日累计 |
| 幻觉防护 | 金额和成功结论来自工具事实与回执 |
| 注入防御 | 严格参数、工具白名单、执行端复核及辅助拦截；未知攻击未全面验证 |
| 操作审计 | 关联plan/node/operation/receipt，清洗敏感字段；hash链缺外部锚 |
| 异常熔断 | 验证失败、通道失败、可疑表达及操作频率触发限制 |
| 受限计算 | 独立数值DSL worker与资源限制，不开放任意Python |
| 模糊与上下文 | 同名或缺槽澄清，有限连续对话；开放语义仍待完整模型验收 |
| DAG | 最多12节点，严格依赖与回执引用，当前顺序扫描执行 |
| 中断与接管 | 暂停、恢复、取消未提交步骤，操作员交还客户；已提交资金冲正未实现 |
