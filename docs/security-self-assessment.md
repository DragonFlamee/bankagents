## 已知风险与处置

| 优先级 | 剩余风险 | 当前处置与后续要求 |
| --- | --- | --- |
| 上线阻断 | 演示身份、公开演示口令、同应用OTP可读存储 | 仅本机合成数据；上线需独立认证服务、真实凭据与回调 |
| 上线阻断 | 模型开放表达、未知注入与恶意工具返回未全面验证 | 旧版固定模型15例与浏览器有证据；新增六场景仅完成离线验收，仍需模型开放集与重复验证 |
| 上线阻断 | 多worker无租约，跨库崩溃窗口未穷尽 | 限单worker；增加持久化租约与崩溃注入测试 |
| 高 | hash链无外部锚，删尾和整体重算不可充分发现 | 保留篡改可见性边界；增加外部签名/锚点、访问控制与备份 |
| 高 | 请求体读入后才检查大小，公网入口未加固 | 仅loopback；上线增加入口流式限制、速率和连接限制、TLS/Host策略 |
| 高 | DSL不是任意代码OS沙箱，POSIX分支未实测 | 只支持数值语言；不开放任意Python，目标平台单独验收 |
| 中 | 异常提示非完整欺诈检测，无全面安全运维/解锁体系 | 不自动判定欺诈，不自动资金处置；需告警和受控运维 |
| 高 | 公网默认演示口令和模型调用无额度控制 | 当前限定本机；对外运行前更换口令、独立认证、增加模型调用限额，不能把写操作频率限制当作Token预算 |
| 中 | 模拟锁定、预约、AA、理财与商户订单没有外部业务连接 | 已实现本地账本状态；goals.create仍不冻结，funds.hold才锁定模拟可用余额；外部冲正未实现 |
| 中 | 订阅识别与查询的授权边界需统一 | subscriptions.get采用黄色，但detect及页面直接返回推断/部分签约信息；提交前复核题面订阅查询要求 |
| 中 | 没有用户研究、开放表达或负载样本 | 当前吸引力为设计假设，后续采集体验和误拦截证据 |

无已知本次固定测试失败被隐藏为通过。G02负金额首次评测因“澄清”与安全异常口径不一致而失败，已保留原JSON，按[协议修订](../evals/protocol-amendment.md)调整预期再测。录屏首次因结果未知后验证弹窗未关闭而失败，已修复前端并重录成功，原失败记录保存在 `artifacts/recording-failure-before-mfa-fix.json`。这不是事前注册或独立安全审计。
